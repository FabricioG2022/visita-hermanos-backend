# Visita de Hermanos - Backend API

API REST para la gestión de miembros y visitas. Desarrollado con Node.js, Express y Firebase Admin SDK.

## 🚀 Requisitos previos e Instalación

Para ejecutar este proyecto en un entorno local, sigue estos pasos:

### 1. Clonar e instalar dependencias

git clone [https://github.com/FabricioG2022/visita-hermanos-backend.git](https://github.com/FabricioG2022/visita-hermanos-backend.git)
